# Leitmix Producciones - Web

Plataforma web oficial de **Leitmix Producciones** para la gestión, visualización y administración de servicios y paneles de control.

## 🚀 Tecnologías utilizadas
* **HTML5 / CSS3** para la estructura y diseño visual.
* **JavaScript (Vanilla)** para la lógica del cliente y la interactividad.
* **Supabase** para la gestión de base de datos y autenticación.

## 📂 Estructura del Proyecto
* `index.html` / `index.js`: Página principal de la web y su lógica de funcionamiento.
* `panel.html` / `panel.js`: Panel de administración y gestión de opciones de cuenta / recibos.
* `config.js` / `supabase.js`: Archivos de configuración y conexión con los servicios de backend (Supabase).
* `sitemap.xml`: Mapa del sitio para optimización en buscadores (SEO).
* `manifest.json`: Configuración de la aplicación web progresiva (PWA).

## 🌐 Despliegue
El proyecto está configurado para actualizarse automáticamente mediante **GitHub Pages**.
